Project Scope Restriction

These engineering standards apply exclusively to this Galaxy Watch 7 Watch Faces repository.

They must govern:

- All existing watch faces in this repository.
- All new watch faces created in this repository.
- All modifications and updates to watch faces in this repository.
- Shared layouts, complication systems, AOD implementations, sensor integrations and validation tools belonging to this repository.

STRICT RESTRICTIONS:

- Do not apply these rules globally to Claude Code.
- Do not modify ~/.claude/CLAUDE.md.
- Do not modify other projects or repositories.
- Do not create shared utilities outside this project.
- Do not change unrelated project configurations.
- Keep all implementation, documentation and testing within this repository unless explicitly authorized.

These instructions are mandatory only within this project.
